# Outcome

把模糊想法整理成目标、范围和关键决策明确的共同理解。

## Steps

1. 目标已明确或用户直接要求实施时退出；否则先查事实，不问可查内容。
2. 每轮只问一个会改变结果的问题，给出推荐答案并等待回答；有 UI 决策时先读取 `rules/ui-interaction-preview.md`。
3. 共同理解最终确认前，只保留在对话，不写项目。
4. 每次回答只解决当前问题。
5. 所有决策后总结共同理解并询问“是否确认并开始实施”；只有对这次最终问题的肯定回答才授权。
6. 得到最终确认后退出并交给实施流程；出现新决策时回到第 2 步。
