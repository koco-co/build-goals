# Outcome

查明事实并逐轮确认真正影响结果的决策，把初步想法整理成明确的共同理解。

## Routing

- 围绕用户提出的目标、想法、计划、设计或决策展开澄清。
- 如果用户的目标已经明确，或只需要普通问答、评审或直接实施，则退出本流程。

## Steps

1. 先查明能够从环境、文件和工具确定的事实。
2. 按依赖顺序，每轮只询问一个会改变结果的问题，给出推荐答案并等待用户回答。
   - 当前决策涉及可见界面或操作流程时，完整读取 `rules/ui-interaction-preview.md`，按其中模板枚举受影响流程的全部界面状态和业务状态流后再请求确认。
3. 所有真实决策解决后，使用用户当前语言总结共同理解并请求最终确认；涉及 UI 时同时展示合并后的完整交互预览。

## Guardrails

- 用户确认共同理解前不实施计划；不替用户决定无法由事实确定的事项。
- UI 探索草稿和最终共同理解只保留在对话，不写入项目文件。

## References

- 当前决策涉及前端、GUI、TUI 或 CLI 的界面与操作变化时，完整读取 `rules/ui-interaction-preview.md`。
