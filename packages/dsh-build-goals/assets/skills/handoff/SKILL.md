# Outcome

将当前对话整理为精简的交接文档，帮助下一位 Agent 在新会话中准确继续工作，同时避免把凭据、密钥或不必要的敏感内容写入临时文件。

## Routing

- 用户传入的参数描述下一次会话的用途，并用于调整交接文档的重点。
- 已知下一次会话使用 Claude Code Plugin 或 Codex 时，生成对应平台的真实 Skill 调用形式；平台未知时使用中性调用说明，不猜测命令。

## Steps

1. 总结当前会话上下文，使下一位 Agent 能够接续工作；只保留目标、约束、已确认决策、当前事实、未完成项和必要证据。
2. 写入前检查内容，不记录访问令牌、密码、私钥、Cookie、完整连接串、真实个人敏感数据或与继续任务无关的秘密；必要信息使用脱敏描述或指出应从原安全来源重新获取。
3. 将交接文档保存到用户操作系统的临时目录，不得保存到当前工作区；创建后将文件权限限制为仅当前用户可读写（POSIX 系统使用 `0600` 或等价权限）。
4. 在文档中加入名为 `suggested skills` 的章节，推荐下一位 Agent 应调用的 Skills，并记录目标平台已知与否。
5. 如果用户传入参数，将其视为下一次会话的用途，并据此调整文档重点。
6. 文档成功写入并确认权限后，为下一个 Agent 生成一段可直接复制的接续提示词；提示词必须引用交接文档的真实文件路径，并要求遵循文档中的目标、约束、已确认决策和后续步骤。
7. `suggested skills` 中存在下一位 Agent 应使用的 Skill 时，按平台生成调用形式：Codex 使用 `$skill-name`；Claude Code Plugin 使用 `/plugin-name:skill-name`；平台或 Plugin 名称未知时写“请调用 `skill-name`”，不得伪造命令。
8. 最终回复提醒交接文档位于临时目录、可能被系统清理；任务完成后建议删除该临时文件，不把它当作长期权威文档。

## Delivery

- 交付一个位于操作系统临时目录、权限仅当前用户可读写的交接文档。
- 文档必须包含 `suggested skills` 章节，并且不包含明文秘密或不必要的敏感数据。
- 文档内容应足够让下一位 Agent 在新会话中恢复上下文并继续工作。
- 最终回复必须同时给出交接文档的真实文件路径，以及标题为 `给下一个 Agent 的提示词` 的独立代码块，确保用户可以直接复制。
- 没有需要调用的 Skill 时，使用以下句式，并将占位内容替换为真实文件路径：

  ```text
  请读取 `<真实文件路径>` 并继续完成其中记录的任务；严格遵循文档中的目标、约束、已确认决策和后续步骤。
  ```

- 存在需要调用的 Skill 时，根据已知平台选择以下形式并替换真实名称与路径：

  ```text
  # Codex
  请使用 `$skill-name`，读取 `<真实文件路径>` 并继续完成其中记录的任务；严格遵循文档中的目标、约束、已确认决策和后续步骤。

  # Claude Code Plugin
  请使用 `/plugin-name:skill-name`，读取 `<真实文件路径>` 并继续完成其中记录的任务；严格遵循文档中的目标、约束、已确认决策和后续步骤。

  # 平台未知
  请调用 `skill-name`，读取 `<真实文件路径>` 并继续完成其中记录的任务；严格遵循文档中的目标、约束、已确认决策和后续步骤。
  ```

## Guardrails

- 不得将交接文档写入当前工作区。
- 不得忽略用户传入的下一次会话用途参数。
- 不得把凭据、密钥、私钥、Cookie、完整连接串或不必要的个人敏感数据复制到交接文件。
- 不得在文件写入并完成权限检查前声称已经生成交接文档，也不得在最终提示词中保留占位路径、不存在的 Skill 名称或未经确认的平台调用语法。
- 临时交接文件不是长期存储；任务完成后应删除，系统提前清理时应从当前权威文件重新生成，而不是依赖不存在的路径。
