# 参考资料样例：Locator 选择速查

> [!abstract] 用途
> 在读者已经理解 Locator 语义后，快速选择候选策略并检查边界。

## 适用范围

用于浏览器自动化测试中的交互目标选择。它不是入门教程，也不替代产品可访问性设计。

## 速查索引

| 页面线索 | 首选方向 | 需要确认 |
| --- | --- | --- |
| 交互角色与稳定名称 | role + accessible name | 名称与角色是否唯一且符合用户认知 |
| 表单标签 | label | 标签是否真正关联控件 |
| 稳定可见文本 | text | 文案、本地化和重复文本是否受控 |
| 产品约定的测试标识 | test id | 是否为受控稳定契约，而非 DOM 结构别名 |

## 参数与行为

| 维度 | 行为 | 风险 |
| --- | --- | --- |
| 精确名称 | 缩小名称匹配范围 | 文案细微变化可能成为显式契约变化 |
| 容器限定 | 在业务区域内继续查找 | 容器不唯一会把问题向上移动 |
| 索引选择 | 从多个候选取一个位置 | 页面顺序变化时可能点击错误目标 |

## 返回值与失败表现

- 零匹配：目标不存在、名称不符、状态未到或上下文错误。
- 多匹配：语义不足以唯一表达业务目标。
- 超时：目标条件在规定边界内未满足；不能仅凭超时断定是网络慢。

## 兼容性

具体 API、默认超时和绑定差异必须按课程固定版本重新核验。本表只规定选择思路。

## 最小示例

```python
page.get_by_role("button", name="提交订单")
```
