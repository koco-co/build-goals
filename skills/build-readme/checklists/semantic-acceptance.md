# README 语义与场景验收

本清单只检查无法由 `scripts/validate_readme.py` 稳定判断的质量。

## 项目真实性

- [ ] 每项功能、限制、兼容、校验、章节和提示都有用户需求、仓库事实、平台契约、可复现缺陷或明确安全要求依据。
- [ ] 一句话定位与当前代码、Manifest 和公开入口一致。
- [ ] 每个功能、命令、参数和配置均有仓库证据。
- [ ] 静态发现、测试通过、真实运行和生产状态没有混淆。
- [ ] 未实现、实验性、已弃用和未知内容被准确标记。
- [ ] 许可证、版本、平台、贡献者和维护状态没有猜测。

## 用户路径

- [ ] 首屏能快速回答项目是什么、为何有用和支持什么。
- [ ] 安装与快速开始提供从安装到首次成功使用的完整、可执行步骤。
- [ ] 主要输入、输出和配置有足够说明；已确认的失败恢复行为得到记录。
- [ ] 详细内部规范以链接引用，不挤占 README 的主要使用说明。

## 视觉与可读性

- [ ] 中文正文为普通字体，英文正文使用 `<b>` 标签，短英文装饰字形符合用户约定，且没有污染命令、路径和代码。
- [ ] 没有使用 Markdown 下划线斜体或 HTML `<i>` / `<em>` 斜体标签。
- [ ] HTML 标签完整配对，章节锚点唯一，代码块保留正确语言标签。
- [ ] Shields 数量适中、含义准确、风格一致、目标链接相关。
- [ ] 每个表格或图表都比等量文字更容易理解。
- [ ] Mermaid、SVG 和图片没有重复表达同一关系。
- [ ] 图片有准确替代文本，并在浅色与深色背景下可读。
- [ ] 装饰内容没有成为理解项目的唯一信息来源。

## 更新与同步

- [ ] 现有有效事实、稳定链接、用户文案和并行修改得到保留。
- [ ] 删除、重组或重命名内容均有理由，必要时保留旧锚点。
- [ ] 只同步实际存在且已确认的伴随 README。
- [ ] 多语言文件中的功能、命令、版本和限制保持一致。

## 交付可信度

- [ ] 所有“已验证”结论均能追溯到实际命令或文件。
- [ ] GitHub API 转换、真实页面视觉检查和发布状态分别记录。
- [ ] 未运行检查和外部阻塞没有被描述为通过。
- [ ] 没有发生未授权的依赖安装、图片生成、提交、推送或发布。
