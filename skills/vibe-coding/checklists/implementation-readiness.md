# 实施就绪清单

## 架构文档

- [ ] 正确的架构文档族已写入并标记为已确认，每个功能域都有对应文件。
- [ ] 文档记录基线 HEAD、来源和最终决策。

## 机械门禁

- [ ] 运行 `python3 <skill-dir>/scripts/validate_delivery.py <root> --mode <greenfield|continuation|migration> --phase plan --strict`，失败项逐条修复。

## 任务追踪（脚本覆盖不到的软判断）

- [ ] 项目路线来自用户自然语言，旧项目“不读取 / 指定范围 / 当前项目基线”边界已明确。
- [ ] 每个配套 Skill 都记录触发证据、调用阶段、阻断性、恢复条件和交付记录。
- [ ] 每个任务定义一次 commit 边界和回滚方式。

## 项目指令

- [ ] 项目指令已归类为“有效沿用”或“已更新并验证”。
- [ ] 需要更新时，`build-agents-md` 的完整正文和文件操作已经确认。
- [ ] 项目指令更新形成只包含根目录或嵌套 `AGENTS.md` / `CLAUDE.md` 的独立治理提交，任务清单已回填明确 SHA。
- [ ] 功能开发共同基线包含冻结的治理提交，之后没有未经确认的项目指令漂移。
- [ ] 无法调用 `build-agents-md` 时流程保持暂停，没有创建功能 worktree。

## 基础工程

- [ ] 实际安装命令、退出状态和关键结果已记录。
- [ ] 启动或等价 smoke 命令已经执行；库项目使用导入、CLI `--help` 或最小示例验证。
- [ ] 基础测试实际运行并通过，证据已进入任务清单。
- [ ] 基础工程提交或“无需变更”的依据已记录。
- [ ] readiness 前已经存在的非当前 worktree 已按“路径 | 分支 | 用途”完整登记；不存在时明确记录 N/A。

## 并行与 Agent

- [ ] 只为确实可以独立执行的任务设计并行组，文件所有权不重叠，共享契约已有明确前置任务。
- [ ] 使用 Agent 时，上下文只包含全局索引、当前功能域、直接依赖契约和当前任务所需文件，并列出适用 `AGENTS.md` 与共同基线。
- [ ] 使用多个 worktree 时，集成责任和顺序明确。

## 用户确认

- [ ] 完整任务方案已在对话中展示。
- [ ] 用户已明确确认任务、并行、提交和验收方案。
- [ ] `docs/实施任务/` 的全局和功能域文件只在第二次全局确认后写入。
