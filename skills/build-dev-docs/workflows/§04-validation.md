# 文档验证

## 文件与引用

按本次最小计划检查：目标文件已写入或更新，保留项未被覆盖，本地链接从引用文件所在目录解析后实际存在。没有选择的文档职责不视为缺失。

若本次创建或更新 AGENT_BRIEF，检查其索引只包含真实文件和准确状态。若修改 AGENTS.md 入口，确认只有一个相关入口且相对路径可定位。Git 项目运行 `git diff --check` 并审阅 Diff，确保没有修改产品代码、机器 Schema 或其他未授权文件。

## 内容

对照 `checklists/acceptance.md` 检查所选文档：

- 事实、设计、实现与验证状态有可定位依据；
- 文档职责清楚，没有复制冲突契约；
- 命令、路径、模块、字段和链接与当前项目一致；
- 模板占位符已清除；
- 未验证项和开放决策没有伪装成完成。

发现范围内问题时修复并重新检查；需要新的产品决策或范围扩张时说明具体影响并询问。

## 交付

报告实际新增或更新的文档、检查命令及结果、未验证项和剩余事项。区分“文档已整理”和“产品已完成”，不执行后续开发或自动提交。
