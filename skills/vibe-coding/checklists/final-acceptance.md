# 最终交付验收清单

## 需求与实现

- [ ] 所有需求、验收 ID 或高优先级迁移发现已闭环。
- [ ] 所有任务有最终状态、commit SHA 和测试证据。
- [ ] 没有未确认范围或隐藏偏离。
- [ ] 架构、目录、代码、测试和文档一致。

## 测试数据与流程

- [ ] 平台中存在可复现的正常测试数据。
- [ ] 主用户旅程以正常数据真实通过。
- [ ] 权限、关联、时间和状态符合业务。
- [ ] 数据与生产隔离并可清理。
- [ ] 日志、截图和报告不含秘密或真实个人数据。

## 机械质量

- [ ] 格式、Lint 和类型检查通过。
- [ ] 构建或打包通过。
- [ ] 单元、集成和 E2E 测试通过。
- [ ] 适用的迁移、契约、性能和恢复测试通过。
- [ ] 没有通过删除测试、弱化断言或关闭规则隐藏失败。
- [ ] CI 与本地命令一致。

## UI 条件分支

- [ ] 无 UI，已记录 Not Applicable；或以下全部适用项通过。
- [ ] 关键视图和用户旅程视觉正确。
- [ ] 响应式、键盘、焦点、语义和对比度符合要求。
- [ ] 加载、空、错误、权限、成功和恢复状态完整。
- [ ] 控制台和网络无未解释错误。
- [ ] 无脏数据、调试文本、占位符、PRD 原文或用户口述文案。
- [ ] 组件、设计 token、输入输出和文案归一化。

## 安全与仓库治理

- [ ] 无已跟踪秘密、真实 token、私钥或生产数据。
- [ ] 环境变量已提取、说明并在启动时校验。
- [ ] 权限、认证、授权和敏感数据路径有测试。
- [ ] 依赖告警无未解释 Blocking/High 风险。
- [ ] AGENTS.md/CLAUDE.md、README 和忽略文件与事实一致。
- [ ] 没有未知生成物、调试日志和临时文件。
- [ ] Git 工作区干净，worktree 无未集成独有修改。
- [ ] 每个已完成且已集成任务的 worktree 和本地任务分支均已立即清理，并有路径、分支及命令证据。
- [ ] 所有保留 worktree 都对应进行中/阻塞任务、独有改动或既有所有权，未被强制删除。

## 交付证据

- [ ] `docs/交付验收报告.md` 完整。
- [ ] 已验证、未验证和阻塞项准确区分。
- [ ] 最终 `validate_delivery.py --phase delivery --require-clean --strict` 通过。
- [ ] 未经授权没有 push、发布、部署或外部数据写入。
