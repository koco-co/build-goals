# 参考资料样例：HTTP 缓存指令速查

> [!question] 要回答的问题
> 当前响应能否被共享缓存保存？多久后必须重新验证？

## 速查索引

按“可缓存性、有效期、重新验证、共享缓存差异”组织，而不是按作者想到的顺序罗列术语。每个条目包含作用对象、与相邻指令的优先关系、失败表现和最小响应头例子。

## 兼容性与版本

协议结论链接当前标准；浏览器、代理或 CDN 的产品行为单独标注核验日期，不把某个实现的默认值写成协议规则。

## 应用证据

给出三个响应头组合，让学习者查表判断私有缓存与共享缓存行为，并说明冲突指令的优先关系。这属于 `reference-application`，不要求背诵整张表。
