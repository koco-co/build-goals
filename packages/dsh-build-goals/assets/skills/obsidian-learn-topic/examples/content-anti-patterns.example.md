# 内容反例与拒绝理由

## 正文混入问答流水账

反例：知识正文含“用户回答”“内部评分”“第 4 次补充”等时间线。拒绝理由：正文无法稳定阅读，学习证据应写入对应的独立记录。

## 知识点重复归属

反例：Locator 正文完整教授 Web-first 断言，下一单元再次从头教授。拒绝理由：一个知识点必须只有一个权威所属单元；其他正文只能简述并 Wikilink。

## 前置依赖倒置

反例：先要求用户审阅 Codegen 生成的 Locator，再教授 Locator 的选择原则。拒绝理由：课程计划必须先通过依赖图检查。

## 只有目录没有验收成果

反例：路线只列“基础、进阶、深入”，没有单元成果和毕业证据。拒绝理由：每个单元必须有一项可观察成果和一种验收方式。
