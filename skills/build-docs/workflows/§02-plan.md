# 整体规划

依据已读取的文档职责表，为全部 12 类文档建立路径映射。已有等价文档沿用现有路径；缺项采用职责表中的默认分组路径。目录迁移另行确认，不因采用新分组自动移动已有文档。一个现有文档确实承担多种职责时可映射到不同章节，不复制第二份正文。

在对话中展示：

| 文档职责 | 实际路径或章节 | 本次操作 | 依据或缺口 | 批次 |
| --- | --- | --- | --- | --- |
| 对应职责 | 新建路径或已有等价文档 | 新建 / 提取补齐 / 更新 / 保留 | 事实或待确认内容 | 依赖顺序 |

默认按“需求与术语 → 架构、数据与决策 → 编码、测试与环境 → 路线与风险”的依赖顺序分批。AGENT_BRIEF 和 CHANGELOG 随每批同步，首次建立时先提供能反映当前进度的简短版本。持续更新只预览受影响批次。

同时展示 AGENTS.md 的一行入口改动，纳入首个相关批次。路径相对于该 AGENTS.md；已有 AGENTS.md 保持其他内容不变，不存在时只创建这一个入口。若已有不同措辞的同用途入口，预览替换该行，不叠加另一个入口。

说明各批次输出、依赖和验收方式，询问是否确认整体规划。确认前不写文件、目录或占位模板；规划确认只允许进入内容预览，不代替每批内容确认。
