# Outcome

将当前对话整理为精简的临时交接文档和一段可直接复制的接续提示词。

## Steps

1. 根据用户给出的下次会话用途，只保留目标、约束、已确认决策、当前事实、未完成项和必要证据。
2. 删除秘密和无关敏感内容，把文档写入操作系统临时目录并限制为仅当前用户可读写。
3. 加入 `Suggested Skills`，只列真实适用的 Skill；写入和权限检查成功后，返回真实路径与可复制提示词。

## Delivery

- 最终回复给出真实文件路径，以及标题为 `给下一个 Agent 的提示词` 的独立代码块。
- 没有适用 Skill 时使用：

  ```text
  请读取 `<真实文件路径>` 并继续完成其中记录的任务；严格遵循文档中的目标、约束、已确认决策和后续步骤。
  ```

- 存在适用 Skill 时使用：

  ```text
  请调用 `skill-name`，读取 `<真实文件路径>` 并继续完成其中记录的任务；严格遵循文档中的目标、约束、已确认决策和后续步骤。
  ```

## Guardrails

- 不写入当前工作区，不保留明文秘密，不虚构路径或 Skill 名称；临时文件可能被系统清理。
