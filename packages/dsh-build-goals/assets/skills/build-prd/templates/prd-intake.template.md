# Build PRD 输入范式

用户可以直接用自然语言说明需求，无需完整填写本模板。信息缺失时，Skill 会先从项目和公开资料中补齐可查事实，再一次只询问一个真正需要用户决定的问题。

```markdown
## 输入模式

- 类型：已有项目 / 产品想法 / 更新已有需求包
- 来源项目：{{已有项目时填写绝对路径；未填写时使用当前目录}}
- 需求包目标项目：{{目标目录}}

## 产品作用

{{希望为哪些用户解决什么问题，以及用户最终能够获得什么结果}}

## 已知用户与场景

- 用户或角色：{{谁会使用或管理这个产品}}
- 核心场景：{{用户会在什么情况下使用，以及希望完成什么}}

## 已确认范围

- 必须包含：{{已经确定需要提供的功能}}
- 明确排除：{{已经确定不纳入本次 PRD 的功能}}

## 已知输入与输出

- 用户实际会提供：{{代表性的自然语言、字段、命令、文件、目录、选项或上下文}}
- 用户期望得到：{{页面内容、处理结果、操作反馈、文件或其他输出}}
- 必须完全一致：{{固定路径、字段、顺序、格式、公开 API 或最终文案}}
- 只需语义一致：{{表达可以变化但必须覆盖的含义}}
- 运行时可变化：{{ID、时间、数量、耗时或环境值}}

## 已有材料

- 产品文档：{{路径或链接}}
- 已有需求包或旧 PRD：{{路径或链接}}
- 已完成的 shape-idea 确认结论：{{粘贴最终确认摘要或说明位于当前会话}}
- 已有竞品、开源项目或官方规范：{{名称与链接}}

## 其他产品要求

{{语言、地区、隐私、无障碍、兼容范围，或其他用户能够感知和验证的要求}}

## 旧项目参考边界

- 必须保持的外部行为：{{命令、路径、格式、API、文件和用户流程}}
- 允许重新设计的内部内容：{{用户确认的范围}}
```
