# 实施就绪清单

## 架构文档

- [ ] 正确的架构文档族已写入并标记为已确认，每个功能域都有对应文件。
- [ ] 文档记录基线 HEAD、来源和最终决策。
- [ ] architecture 阶段机械校验通过。

## 任务追踪

- [ ] 每个任务有唯一 `TASK-NNN`。
- [ ] 需求包的每个 `F-NNN`、`F-NNN-AC-NN` 和行为样例都有功能域任务与测试映射。
- [ ] 迁移路线的每个 Blocking/High Finding 都有处理结果。
- [ ] 每个任务有输入、输出、依赖、文件范围和完成条件。
- [ ] 每个任务定义第一条失败测试、测试数据和验证命令。
- [ ] 每个任务定义一次 commit 边界和回滚方式。
- [ ] 每个配套 Skill 都记录触发证据、调用阶段、阻断性、恢复条件和交付记录。

## 项目指令

- [ ] 项目指令已归类为“有效沿用”或“已更新并验证”。
- [ ] 需要更新时，`build-agents-md` 的完整正文和文件操作已经确认。
- [ ] `validate_agents_md.py --strict --require-symlink` 与适用的真实项目命令已经运行并记录结果。
- [ ] 项目指令更新形成只包含根目录或嵌套 `AGENTS.md` / `CLAUDE.md` 的独立治理提交，任务清单已回填明确 SHA。
- [ ] 功能开发共同基线包含冻结的治理提交，之后没有未经确认的项目指令漂移。
- [ ] 无法调用 `build-agents-md` 时流程保持暂停，没有创建功能 worktree。
- [ ] readiness 阶段机械校验通过。

## 基础工程

- [ ] 实际安装命令、退出状态和关键结果已记录。
- [ ] 启动或等价 smoke 命令已经执行；库项目使用导入、CLI `--help` 或最小示例验证。
- [ ] 基础测试实际运行并通过，证据已进入任务清单。
- [ ] 基础工程提交或“无需变更”的依据已记录。
- [ ] readiness 前已经存在的非当前 worktree 已按“路径 | 分支 | 用途”完整登记；不存在时明确记录 N/A。

## 并行与 Agent

- [ ] 关键路径和并行组明确。
- [ ] 并行任务的文件所有权不重叠。
- [ ] 共享契约由明确前置任务冻结。
- [ ] 每个 Agent 只获得全局索引、当前功能域、直接依赖契约和当前任务所需文件，并有明确返回格式。
- [ ] 每个 Agent 的上下文包列出适用 `AGENTS.md` 路径、读取状态和共同基线。
- [ ] Integration Manager 唯一且集成顺序明确。
- [ ] 平台不支持并发时有串行降级方案。

## 用户确认

- [ ] 完整任务方案已在对话中展示。
- [ ] 用户已明确确认任务、并行、提交和验收方案。
- [ ] `docs/实施任务/` 的全局和功能域文件只在第二次全局确认后写入。
- [ ] plan 阶段机械校验通过。
