# Build PRD 输入范式

用户可以直接用自然语言说明需求，无需完整填写本模板。信息缺失时，Skill 会先从项目和公开资料中补齐可查事实，再一次只询问一个真正需要用户决定的问题。

```markdown
## 输入模式

- 类型：已有项目 / 产品想法
- 项目目录：{{已有项目时填写；未填写时使用当前目录}}

## 产品作用

{{希望为哪些用户解决什么问题，以及用户最终能够获得什么结果}}

## 已知用户与场景

- 用户或角色：{{谁会使用或管理这个产品}}
- 核心场景：{{用户会在什么情况下使用，以及希望完成什么}}

## 已确认范围

- 必须包含：{{已经确定需要提供的功能}}
- 明确排除：{{已经确定不纳入本次 PRD 的功能}}

## 已知输入与输出

- 用户会提供：{{文字、字段、文件、选项或其他内容}}
- 用户期望得到：{{页面内容、处理结果、操作反馈、文件或其他输出}}

## 已有材料

- 产品文档：{{路径或链接}}
- 已有 PRD：{{路径或链接}}
- 已完成的 shape-idea 确认结论：{{粘贴最终确认摘要或说明位于当前会话}}
- 已有竞品、开源项目或官方规范：{{名称与链接}}

## 其他产品要求

{{语言、地区、隐私、无障碍、兼容范围，或其他用户能够感知和验证的要求}}
```
