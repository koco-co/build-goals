# Outcome

生成精简的临时交接文档和一段可直接复制的接续提示词。

## Steps

1. 按用户给出的下次会话用途确定交接目标，只保留目标、约束、已确认决策、当前事实、未完成项和必要证据，删除秘密及无关敏感内容。
2. 将文档写入仅当前用户可读写的操作系统临时目录。
3. 在文档中加入 `Suggested Skills` 一节，只列真实适用的 Skill；确认写入成功后返回路径和提示词。

## Output

- 最终回复给出真实文件路径，以及标题为 `给下一个 Agent 的提示词` 的独立代码块。
- 没有适用 Skill 时使用：

  ```text
  请读取 `<真实文件路径>` 并继续完成其中记录的任务；严格遵循文档中的目标、约束、已确认决策和后续步骤。
  ```

- 存在适用 Skill 时使用：

  ```text
  请调用 `skill-name`，读取 `<真实文件路径>` 并继续完成其中记录的任务；严格遵循文档中的目标、约束、已确认决策和后续步骤。
  ```

## Rules

- 不写入当前工作区，不保留明文秘密，不虚构路径或 Skill 名称；临时文件可能被系统清理。
