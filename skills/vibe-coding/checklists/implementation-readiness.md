# 实施就绪清单

## 架构文档

- [ ] 正确的架构文档已写入并标记为已确认。
- [ ] 文档记录基线 HEAD、来源和最终决策。
- [ ] architecture 阶段机械校验通过。

## 任务追踪

- [ ] 每个任务有唯一 `TASK-NNN`。
- [ ] PRD 的每个 `F-NNN` 和 `F-NNN-AC-NN` 都有任务映射。
- [ ] 迁移路线的每个 Blocking/High Finding 都有处理结果。
- [ ] 每个任务有输入、输出、依赖、文件范围和完成条件。
- [ ] 每个任务定义第一条失败测试、测试数据和验证命令。
- [ ] 每个任务定义一次 commit 边界和回滚方式。

## 并行与 Agent

- [ ] 关键路径和并行组明确。
- [ ] 并行任务的文件所有权不重叠。
- [ ] 共享契约由明确前置任务冻结。
- [ ] 每个 Agent 有最小上下文包和返回格式。
- [ ] Integration Manager 唯一且集成顺序明确。
- [ ] 平台不支持并发时有串行降级方案。

## 用户确认

- [ ] 完整任务方案已在对话中展示。
- [ ] 用户已明确确认任务、并行、提交和验收方案。
- [ ] `docs/实施任务清单.md` 只在确认后写入。
- [ ] plan 阶段机械校验通过。
