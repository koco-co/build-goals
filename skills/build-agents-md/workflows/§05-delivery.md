# §05 交付

## 结果优先

先说明最终建立了哪些指令作用域、单一来源是否成立、验证是否通过。随后给出可定位的文件链接和必要的复现命令。

## 必须报告

- 新增、整体替换、删除和链接的文件；
- 每个嵌套文件的存在理由；
- 旧 Claude 专有规则如何泛化、保留或经确认移除；
- 实际执行的命令与结果；
- “来源已确认、运行未验证”的命令及原因；
- 未做的真实 Claude Code/Codex 加载验证或其他阻塞项；
- 明确未创建的项目文档、lint、CI 或 harness。

不要把校验器 PASS 扩大为“项目完全正确”或“两个客户端已验收”。

## 后续动作确认

实现和验证全部结束后，判断以下动作对当前仓库是否适用：

- commit；
- push；
- 更新本地 Claude Code Plugin；
- 更新本地 Codex Plugin。

只把适用动作放进一次确认问题，并允许用户逐项授权。未得到明确确认前不得执行；确认 commit 不等于确认 push，确认一个客户端更新也不等于确认另一个。

若用户暂不授权，交付仍然完成，保留清晰的工作区状态和建议提交说明即可。
